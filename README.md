## ✨ 功能特性

### 🚀 全自动挂机引擎（点火启动）

- **视频托管**：自动播放、倍速（1.0x–3.0x 可选）、静音、拦截站点的"切后台暂停"指令
- **后台免疫**：伪装页面可见 / 焦点锁死，切标签页、开全屏打游戏都不暂停；音频心跳防浏览器后台降频；屏幕常亮锁（WakeLock）
- **弹窗小题秒杀**：三层策略，答完自动收尾（关题层 + 清遮罩 + 恢复播放）——
  1. 🎯 **内存嗅探**：答案明文存在于 `div[uooc-video]` 的 `source` 属性，直接读取（100% 准确）
  2. 🗳️ **LLM 采样投票**：同一道题并行问模型 3 次取多数，票数并列再补问 2 次重投（借鉴 fastuooc 的 self-consistency 方案，显著降低单次幻觉答错率）
  3. 🔨 **穷举兜底**：嗅探/LLM 都没命中时按位掩码穷举，凭站点即时判分锁定正确项（弹窗小题分值低，穷举代价可接受；**考试/章节测验不走盲穷举**，见下方闯关流水线）
  - 🛡️ **智能验证保护**：检测到阿里云智能验证等验证弹窗时，暂停自动作答与遮罩清理，交人工完成，避免误杀验证层导致整页无法交卷
- **自动前进**：视频播完自动跳下一节；章节自动展开（带 3.5s 冷静期）；附件 / 讨论 / 文本 / 文档等无视频小节自动跨越；课程封顶自动停止
- **大考警报**：检测到独立测验（结构性判据，"软件测试"这类课程名不误判）立刻挂起引擎，语音 + 日志双重提醒人工交卷；已提交（绿勾）的测验自动跳过
- **状态记忆**：引擎运行状态持久化，刷新页面 / 切换课程自动续跑；随时可 ⏹ 停止
- **急救工具**：🔄 强制刷新兜底；🧹 一键清理卡死的弹窗遮罩，恢复页面点击

### 🤖 AI 智能答题（LLM）

- 支持**任意 OpenAI 兼容接口**（OpenAI / DeepSeek / 通义 / 中转站均可），Base URL 填根地址、`/v1` 或完整 `chat/completions` 都能自动规范化
- 考试 / 测评页一键整卷作答：提取题目 → **3 路采样投票**（票数并列自动补问 2 轮）→ 自动勾选 → 人工复核后提交
- 学习页弹窗小题自动接入 LLM 采样投票
- 🚧 **闯关模式**（学习页章节测验，面板可开关）：LLM 投票作答 → 自动交卷 → 读每题判分 → 未通过则**只重做错题**（换提示 + 升温重采样，已对的题不动）→ 仍不过则**只爆破错题**（锁定对题，逐道错题穷举候选，每次提交按判分锁定，把 0 分题往对了改）
- `/exam/` 考试页**永不自动交卷、不穷举**，只填答案留人工提交
- 请求由扩展后台 Service Worker 发出，**API Key 只存本地** `chrome.storage.local`，不进入网页环境

### 🎛️ 视频助手（手动模式，不点火也可用）

- 倍速 / 静音 / 播放 / 连播 / 弹窗秒答 独立开关，随时启停
- 键盘快捷键：`←` `→` 快退 / 快进 10s（右方向需小节完成）、`↑` `↓` 音量、`空格` 播放 / 暂停
- **📋 复制题目答案**：在已提交的测验回顾页，把题目 + 答案 + 对错一键复制到剪切板

### ⚡ 实验性直连接口（v3.0.0）

- **接口直答**（默认开，仅学习页章节测验）：闯关流水线前置尝试 `getTaskPaper` 取卷 → 泄漏答案优先 / LLM 投票 → `commit` 逐题判分 → 错题接口级穷举（100ms/次，200 次上限）→ 整卷提交。任何一步失败自动回退页面答题流程；**`/exam/` 考试页永不使用**
- **App Token（可选）**：设置页可填手机 App 抓包的 Bearer Token，请求附加 Android 客户端头；默认走页面登录会话（同源 Cookie），无需额外凭据。凭据只保存在本地 `chrome.storage.local`

### 💬 讨论区 AI 发帖（v3.1.1）

- 引擎运行且处于课程**讨论视图**时自动接管：遍历帖子列表 → LLM 依据标题+正文生成 80~200 字的学生口吻回复（温度 0.7，禁套话/禁 AI 腔）→ 经站点自身的 `courseService.discReply` 提交
- 回完自动回列表找下一篇，全部回完自动回学习视图继续挂机；已回帖按课程持久化去重，重进不重复发
- 需要「LLM 答题」开关 + 已配置 API；面板/Popup/设置页均可关闭

### 🖥️ 控制台

左上角悬浮面板：可拖拽、可收起成小球、实时日志滚动输出引擎的每一个动作（嗅探命中 / 穷举尝试 / 目标锁定 / 警报……）。

## 📦 安装

### 方式一：下载 Release（推荐）

1. 到 [Releases](../../releases) 下载最新的 `uooc-assistant-pro-vX.X.X.zip` 并解压
2. Chrome / Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择解压出的文件夹

### 方式二：源码加载

克隆 / 下载本仓库，同上选择仓库目录即可。

> ⚠️ 如果之前装过 Tampermonkey 版的《UOOC assistant》或《UOOC 助手》，请先停用它们，避免重复注入互相干扰。

## 🔧 AI 配置

点击面板 ⚙️（或工具栏扩展弹窗里的「AI 设置」）打开设置页：

1. 填写 **API Base URL**（如 `https://api.openai.com/v1`）、**API Key**、模型名（可选）
2. 点「保存」——首次保存会请求该 API 域名的跨域访问权限（只授这一个域名）
3. 点「测试连接」验证

## 🧭 工作原理（技术向）

| 模块 | 说明 |
|---|---|
| 隐身模块 | `document_start` 阶段覆写 `document.hidden` / `visibilityState` / `hasFocus`，并在捕获阶段拦截 `visibilitychange` / `blur` / `focus`；**仅作用于学习页**，考试页不启用，避免干扰切屏检测 |
| 视频守护 | 替换 `video.pause` 为拦截版（弹窗显示时放行让站点状态机复位），`loadstart` / `play` 捕获阶段即时接管新视频，杜绝 1x + 满音量空窗期 |
| 弹窗判定 | `#quizLayer / .smallTest-view`；空壳弹窗 4s 宽限后"斩杀"，孤儿 layui 遮罩每轮自愈清理 |
| 交卷判据 | 优课弹窗小题答完**不会消失**（长在视频下方），以"题目块文本是否变化"作为交卷受理信号，同时校验小节指纹防止"页面跳走"被误判为答对；只在确认受理后才收尾，未受理保留弹层给人工 |
| 智能验证保护 | 文本特征识别验证类弹层（验证/智能/安全/提交，排除题目层自身），在屏时冻结自动作答与遮罩回收 |
| 实验性直连接口 | 闯关前置 `getTaskPaper`/`commit` 接口直答（逐题判分穷举，失败回退页面流程，/exam/ 不参与）；可选 App Token 附加 Android 头 |
| 闯关流水线 | 自动交卷（处理 layui 确认框与智能验证）→ 按 `.scores` 红标/得分比对判每题对错 → LLM 只重做错题 → 只爆破错题：多选按子集大小 2→3→…→1 排序候选、单选逐项，跳过已判错组合，每次提交后按判分锁定，全局 60 次提交上限 |
| 章节雷达 | 切到「目录」后收集侧边栏全部条目，按 active 指纹定位当前项，点击下一项；`lastSuccessIdx` 兜底记忆 |
| 无视频跨越 | 无视频 + 非测验 + 无弹窗持续 6s（附件 3s）自动跳下一项，任何资源类型都不会卡死 |
| 大考判据 | 结构性三条件：无 `.icon-video` + 资源标签含 测验/考试/试卷 + 页面级题目或"保存试卷"，杜绝按课程名误判 |
| 数据同步 | 面板 / popup / 设置页 三端通过 `chrome.storage.local` + `onChanged` 实时同步 |

## ❓ FAQ

**Q: 点火后没反应？**
先确认当前在课程学习页（URL 含 `/home/learn/index`），日志窗口应有输出；若页面结构加载慢，等目录渲染完成后再点火。

**Q: 弹窗小题会穷举吗？分数会不会越刷越低？**
弹窗小题（视频中弹出的小测）分值低且有即时判分，开启「弹窗秒答」后走 嗅探 → LLM投票 → 穷举兜底，答对即锁定。章节测验**不做盲穷举**——闯关模式只在 LLM 两轮都失败后，锁定已对的题、只对已经 0 分的错题穷举，只会把分数往高了改。`/exam/` 考试页则完全不自动交卷。

**Q: AI 答题报 CORS / Failed to fetch？**
到设置页重新点一次「保存」并同意跨域授权弹窗；Base URL 填根地址或 `/v1` 结尾均可，会自动补全。

**Q: 会封号吗？**
任何刷课行为都有风险，请自行评估。本工具仅作技术学习交流用途。
